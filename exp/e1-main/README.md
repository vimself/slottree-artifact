## 3. 开发记录与偏离

**环境**：Apple M4（10 核）、16 GB、macOS 26（Darwin 25.6.0）、接电源；`Apple clang version 21.0.0 (clang-2100.3.34.2)`（Target arm64-apple-darwin25.6.0），`-O2 -std=c++20 -Wall -Wextra`（同 M1），单线程。每次跑的 HEAD、电源记在 `logs/env_<mode>.txt`。

**引擎**（`src/trend.cpp`，从 M1 复制后改；看计时数据之前定的实现事实）：
- OPP 路径与 M1 的 diff（`python3 -I tests/diff_opp.py`）：`Fin`、`Scan`、`ArmBase`、`own_from_acc` 相同；`ArmOPP` 只多一个默认关掉的模板参数 `XN`（E2 的选择度谓词，`if constexpr`），E1 的实例化与 M1 逐行相同
- M 的扫描模式用 `ScanC`：继承 OPP 的 `Scan`（结构、purge、insert 不改），查询循环同 `Scan` 的有序数组分支，每个窗格多一次乘加数出本事件的窗口累加次数（合格前驱数 × |共同窗口|）
- 子树槽多存 nev（E4 第 2.1 节）；M、A2、A4、A5 是同一棵树（都带 nev），差别只在切换规则与过期方式。规则的 EWMA 用 double，ī 的 ⌈log₂(n_live + 2)⌉ 用前导零计数，n_live 取事件到达时该组的活事件数
- A2：每组一个按到达序的结点队列；组的窗格边界上队首 π_x ≤ π − k 的结点逐个删（按键下降找到、把优先级大的孩子旋上来直到成叶、摘掉、自底向上重算路径上 J(π) 的 k 个槽），删掉的结点号进空闲表重用，不压缩
- 短行加长（`--copies D`）：引擎内把排好序的流复制 D 份，第 c 份时间平移 c × span，span = (⌊(t_max − t_min) ÷ s⌋ + 1) · s（整段时长按整窗格取整，窗格对齐、各份不重叠）
- **D 的定法**：每行先用 OPP 与 M 各跑一遍预热（D = 1）取小的，< 5 ms 就 D = min(50, ⌈5 ms ÷ 它⌉)，该行全部臂、全部进程用同一个 D（判据只说「预热遍 < 5 ms 的行」；取 r 的两个臂里快的那个，保证两者都过 5 ms）
- `--autopasses`：1 遍预热后 R = min(200, max(5, ⌈2 s ÷ 预热遍⌉))；每个臂各按自己的预热定 R
- 工作量计数（`--work`）只在每行的第 1 个进程另跑一遍（不计时），同一遍出 M 的索引模式事件数与 s̄ ÷ ī 的中位
- E6（11-08，补充实验 ⑤）加 `--latency <文件>`（逐事件计时），默认关、只动驱动（`run_arm` 开头一次指针判空，各臂结构体不改）；加完后闸 (a)(b)(c) 重过全过，新旧二进制计时差在噪声内（`exp/e6-latency/README.md` 第 2 节）。E5、E6、E7 用的是这一版
- E2 的 `--xnum`：谓词 a_p · X_num ⋈ a_e · 1000 换成对 a_p 的整数阈值（> 时 a_p > ⌊a_e · 1000 ÷ X_num⌋，< 时 a_p < ⌈a_e · 1000 ÷ X_num⌉，128 位整数算），树与顶点树照常按 a_p 查；X ≠ 1 时树的插入路径另走一遍
